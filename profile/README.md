# GoalT

A free, open source (Apache 2.0) goal tree for Claude Code. It maps why every
part of a project exists, computes which goal matters most right now, and shows
what Claude is working on in a live local dashboard.

- **Website:** [goalt.org](https://www.goalt.org/)
- **Install the plugin:** in Claude Code run `/plugin marketplace add GOAL-T/goaltree`,
  then `/plugin install goalt@goalt-marketplace`. Needs Python 3.10+ with
  `python3 -m pip install "goaltree[mcp]"`.
- **Python package:** `python3 -m pip install goaltree` ([PyPI](https://pypi.org/project/goaltree/))
- **Docs:** [goalt.org/docs](https://www.goalt.org/docs)
- **Source:** [GOAL-T/goaltree](https://github.com/GOAL-T/goaltree)

No account, and nothing leaves your machine. GoalT is made independently, not
by Anthropic.
